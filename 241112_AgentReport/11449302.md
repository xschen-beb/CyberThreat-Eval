#### Incident: Ymir Ransomware Attack in Colombia 

#### Root cause 
 The root cause includes the use of PowerShell remote control commands to gain access, followed by the deployment of multiple malicious tools and the Ymir ransomware. The initial access was facilitated by the RustyStealer malware, compromising legitimate user credentials and allowing lateral movement using WinRM and PowerShell. Tools such as Advanced IP Scanner and Process Hacker were used to reduce system security and assist in the deployment of Ymir ransomware. *Ymir operates entirely from memory and uses in-memory execution techniques, including functions like 'malloc,' 'memmove,' and 'memcmp,' to evade detection. It also employs memory manipulation and anti-forensics techniques, importing functions from operating system libraries, including Windows-native API calls for encryption and process termination, and employs a self-destruct command to delete itself post-execution* (https://candid.technology/ymir-ransomware-targets-enterprises-with-memory-manipulation/). 

#### Threat actor/group/campaign 
 The specific threat actor group behind the Ymir ransomware is not identified, but the attack involved the use of the RustyStealer malware and the deployment of the SystemBC proxy malware. *The Biden administration highlighted the threat posed by ransomware, urging UN member states to strengthen cybersecurity* (https://webboard-nsoc.ncsa.or.th/post/1542). 

#### Organization/industry/location 
 The known target of this incident is an organization in Colombia. 

#### Start date – End date 
 The exact dates of the attack are not specified, but the attack was reported on November 11, 2024. *Ymir ransomware operation launched in July 2024* (https://www.bleepingcomputer.com/news/security/new-ymir-ransomware-partners-with-rustystealer-in-attacks/). 

#### MITRE TTPs 
 ['Discovery: File and Directory Discovery (T1083)', 'Discovery: System Information Discovery (T1082)', 'Execution: Command and Scripting Interpreter: PowerShell (T1059.001)', 'Impact: Data Encrypted for Impact (T1486)', 'Defense Evasion: Virtualization/Sandbox Evasion: Time Based Evasion (T1497.003)', 'Defense Evasion: Indicator Removal: File Deletion (T1070.004)'] 

#### Impact 
 The attack led to the encryption of data on the compromised systems, with the ransomware demanding a ransom for decryption. The exact number of records or financial losses are not specified. The ransom note was named 'INCIDENT_REPORT.pdf' and was created using a PDF file embedded in the malware. *Ymir uses the ChaCha20 stream cipher to encrypt files, appending a random extension like '.6C5oy2dVr6,' and modifies the Windows Registry 'legalnoticecaption' value to show an extortion demand* (https://www.bleepingcomputer.com/news/security/new-ymir-ransomware-partners-with-rustystealer-in-attacks/). 

#### Mitigation Steps 
 ['Secure remote access: Ensure that remote access tools like PowerShell and WinRM are properly secured and monitored.', 'Endpoint protection: Deploy and maintain robust endpoint protection solutions to detect and block malware like RustyStealer and Ymir ransomware.', 'User training: Train employees on recognizing phishing attempts and the importance of secure credentials.', 'Network segmentation: Segment the network to limit the lateral movement of attackers.', 'Regular backups: Maintain regular, secure backups of critical data to ensure data can be restored in case of ransomware attacks.']
