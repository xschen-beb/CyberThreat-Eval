This folder contains tools for deep analysis of articles. You should generate related URLs from the given ground truth dataset (`0510-articles.json`).

## Project Structure

```
deep_search/
├── 0510-articles.json            # Ground truth dataset
├── llm.py                        # LLM integration utilities
├── process_articles.py           # Generates related URLs for given inputs
├── process_related_similarity.py # Check additional info for related URLs generated by process_articles.py
└── calculate_model_statistics.py # Statistical analysis results
```

## Usage
Step 1: Process articles to get related URLs
```bash
python process_articles.py --json_file 0510-articles.json --output_dir processed_results --model [model_name]
```
This step will:
- Process each article from the ground truth dataset
- Find related URLs for each article
- Save results in the processed_results directory

 Step 2: Analyze related URLs for additional information
```bash
python process_related_similarity.py --results_dir processed_results --output_dir similarity_analyses
```
This step will:
- Analyze relationships between URLs
- Identify URLs with additional information
- Generate similarity analysis reports
- Create network graphs

Step 3: Calculate model statistics
```bash
python calculate_model_statistics.py
```
