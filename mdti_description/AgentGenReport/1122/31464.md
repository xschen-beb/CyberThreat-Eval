#### Incident: Infostealer Searching for BIP-0039 Data 

#### Root cause 
 The root cause of this incident is the execution of a malicious Python script that installs the mnemonic Python module, which is used for generating and validating mnemonic phrases (BIP-0039). The script is designed to search for mnemonic phrases in files and exfiltrate them if found. The primary vulnerability here is the execution of untrusted scripts that can install additional modules and perform unauthorized actions on the system. 

#### Threat actor/group/campaign 
 BIPClip campaign *The campaign was reported by Xavier Mertens on November 22, 2024* (https://isc.sans.edu/forums/diary/An+Infostealer+Searching+for+BIP0039+Data/31464/). *The BIPClip campaign was also identified by ReversingLabs* (https://www.reversinglabs.com/blog/bipclip-malicious-pypi-packages-target-crypto-wallet-recovery-passwords). 

#### Organization/industry/location 
 Crypto wallet developers *The campaign targeted developers working on cryptocurrency wallets* (https://www.reversinglabs.com/blog/bipclip-malicious-pypi-packages-target-crypto-wallet-recovery-passwords). 

#### Start date – End date 
 December 2022 – March 2024 *The campaign involved packages dating back to December 2022 and continued until March 2024* (https://www.reversinglabs.com/blog/bipclip-malicious-pypi-packages-target-crypto-wallet-recovery-passwords).

#### Impact 
 Potential theft of cryptocurrency due to the compromise of mnemonic phrases used in cryptocurrency wallets. *The compromised packages had limited downloads, but one package had 4,295 downloads, indicating a significant potential impact* (https://www.reversinglabs.com/blog/bipclip-malicious-pypi-packages-target-crypto-wallet-recovery-passwords).
