#### Incident: Ymir Ransomware Attack in Colombia 

#### Root cause 
 The attackers gained initial access through PowerShell remote control commands and then deployed tools like Process Hacker and Advanced IP Scanner to compromise the system further. The root cause likely includes misconfigured or unmonitored remote access services and insufficient endpoint security controls. *The attackers also utilized the malloc, memmove, and memcmp function calls for memory operations* (https://securelist.com/new-ymir-ransomware-found-in-colombia/114493/). *Ymir operates entirely from memory, leveraging in-memory execution to evade detection* (https://www.bleepingcomputer.com/news/security/new-ymir-ransomware-partners-with-rustystealer-in-attacks/). *Attackers used the --path command to specify directories for encryption, adding flexibility in target selection* (https://www.kaspersky.com/about/press-releases/kaspersky-identifies-new-stealthy-ransomware). 

#### Threat actor/group/campaign 
 The specific threat actor behind the Ymir ransomware is not identified. However, the campaign included the use of RustyStealer and SystemBC malware, indicating a coordinated effort. *The malware also imported functions such as CryptAcquireContextA, CryptReleaseContext, CryptGenRandom, TerminateProcess, and WinExec* (https://securelist.com/new-ymir-ransomware-found-in-colombia/114493/). *The attack utilized the ChaCha20 stream cipher for file encryption* (https://www.bleepingcomputer.com/news/security/new-ymir-ransomware-partners-with-rustystealer-in-attacks/). *Initial access brokers used RustyStealer to steal credentials and maintain access, potentially indicating a new trend* (https://www.kaspersky.com/about/press-releases/kaspersky-identifies-new-stealthy-ransomware). 

#### Organization/industry/location 
 The incident targeted an organization in Colombia. 

#### Start date – End date 
 The incident was detected two days after the initial RustyStealer intrusion, indicating that the attack likely occurred between August 31, 2024, and November 11, 2024. *The PDF creation date of the ransom note was August 31, 2024, matching the binary compilation timestamp* (https://securelist.com/new-ymir-ransomware-found-in-colombia/114493/).

#### Impact 
 The Ymir ransomware encrypted files and placed ransom notes in various directories, severely impacting the victim's operations. *The ransom notes were PDF files named 'INCIDENT_REPORT.pdf'* (https://securelist.com/new-ymir-ransomware-found-in-colombia/114493/). *The ransomware modified the Windows Registry 'legalnoticecaption' value to display an extortion demand before login* (https://www.bleepingcomputer.com/news/security/new-ymir-ransomware-partners-with-rustystealer-in-attacks/).
