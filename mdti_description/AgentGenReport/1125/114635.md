#### Incident: Elpaco Ransomware Attack 

#### Root cause 
 The Elpaco ransomware attack exploited a brute-force attack to gain access via RDP and elevated privileges via the Zerologon (CVE-2020-1472) vulnerability. The ransomware abused the Everything library for file discovery and customization, specifically leveraging Everything32.dll functions (https://www.trendmicro.com/pt_br/research/23/a/new-mimic-ransomware-abuses-everything-apis-for-its-encryption-p.html). The attack involved disabling security mechanisms, including disabling Windows telemetry (https://www.trendmicro.com/pt_br/research/23/a/new-mimic-ransomware-abuses-everything-apis-for-its-encryption-p.html), and running system commands using legitimate tools like 7-Zip and xdel.exe. Additionally, the ransomware used a 'svhostss.exe' binary that mimicked 'svchost.exe', dropped a 'session.tmp' file for resuming encryption, employed the Defender Control tool (DC.exe) to disable Windows Defender, and featured multi-threaded encryption to speed up the attack. It also utilized the 7za.exe for payload extraction, employed the fsutil command for zeroing out files, and appended the '.QUIETPLACE file extension' (https://www.trendmicro.com/pt_br/research/23/a/new-mimic-ransomware-abuses-everything-apis-for-its-encryption-p.html). Notably, Elpaco ransomware shares code similarities with the Conti builder (https://www.trendmicro.com/pt_br/research/23/a/new-mimic-ransomware-abuses-everything-apis-for-its-encryption-p.html). The attack also involved targeting MSSQL servers using brute-force attacks to deliver ransomware payloads, leveraging xp_cmdshell for command execution, and downloading the Cobalt Strike beacon via PowerShell (http://88.214.26.3:25823/189Jt) *Your changes* (https://www.securonix.com/blog/securonix-threat-research-security-advisory-new-returgence-attack-campaign-turkish-hackers-target-mssql-servers-to-deliver-domain-wide-mimic-ransomware/).
