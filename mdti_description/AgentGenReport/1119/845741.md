#### Incident: XLoader Executed Through JAR Signing Tool (jarsigner.exe) 

#### Root cause 
 The root cause behind the incident is the use of DLL side-loading technique, where a legitimate application (jarsigner.exe) is used to load a malicious DLL (jli.dll) that decrypts and injects another malicious DLL (concrt140e.dll) containing the XLoader malware. *The legitimate file was renamed to Documents2012.exe and the malicious DLLs were not signed* (https://asec.ahnlab.com/en/84574/). 

#### Threat actor/group/campaign 
 Not specified in the document. 

#### Organization/industry/location 
 *Eclipse Foundation* (https://asec.ahnlab.com/en/84574/). 

#### Start date – End date 
 Not specified in the document. 

#### MITRE TTPs 
 ['T1073: DLL Side-Loading', 'T1055: Process Injection', 'T1027: Obfuscated Files or Information'] 

#### Impact 
 The impact includes the theft of sensitive information such as the user’s PC and browser information, and the potential downloading of additional malware. *The injected malware, XLoader, is executed through aspnet_wp.exe* (https://asec.ahnlab.com/en/84574/). 

#### Mitigation Steps 
 ['Ensure that all software and applications are obtained from trusted sources and are verified before execution.', 'Implement strict access controls to prevent unauthorized modifications to application directories.', 'Regularly update and patch software to mitigate vulnerabilities that could be exploited by DLL side-loading techniques.', 'Use endpoint protection solutions that can detect and block malicious activities, including DLL side-loading and process injection.', 'Educate users about the risks of executing files from untrusted sources and encourage them to report suspicious activities.']
