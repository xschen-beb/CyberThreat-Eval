# MAR-10454006-r2.v1 SEASPY Backdoor

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: SEASPY Backdoor 

 Root cause: The root cause is the exploitation of CVE-2023-2868, a zero-day vulnerability affecting versions 5.1.3.001-9.2.0.006 of Barracuda Email Security Gateway (ESG). Attackers used this vulnerability to install SEASPY malware, a persistent and passive backdoor masquerading as a legitimate Barracuda service 'BarracudaMailService.' *The attackers can inject malicious reverse shell command via crafted TAR files* (https://teamt5.org/en/posts/cve-2023-2868-barracuda-email-security-gateway-vulnerability/). *Mandiant investigation revealed the attackers also used SALTWATER, SEASIDE, SUBMARINE, and WHIRLPOOL malware families in their campaign* (https://cloud.google.com/blog/topics/threat-intelligence/barracuda-esg-exploited-globally). *Additional malware families SKIPJACK and FOXTROT/FOXGLOVE were used for persistence and lateral movement* (https://www.tenable.com/blog/cve-2023-2868-barracuda-and-fbi-recommend-replacing-email-security-gateway-esg-devices). *Rapid7 incident response teams are investigating exploitation of Barracuda ESG appliances* (https://www.rapid7.com/blog/post/2023/06/08/etr-cve-2023-2868-total-compromise-of-physical-barracuda-esg-appliances/). 

 Threat Actor/group/campaign: *China-nexus UNC4841* (https://teamt5.org/en/posts/cve-2023-2868-barracuda-email-security-gateway-vulnerability/) 

 Organization/industry/location: The affected organization is not explicitly mentioned, but it involves entities using Barracuda Email Security Gateway. *Targets include U.S. government entities, Chinese IT firms, research institutes in Taiwan, and Pakistani banks* (https://teamt5.org/en/posts/cve-2023-2868-barracuda-email-security-gateway-vulnerability/). 

 Start date – End date: The specific dates of the attack are not provided, but the report was released on July 28, 2023. *Attacks can be traced back to at least October 2022* (https://teamt5.org/en/posts/cve-2023-2868-barracuda-email-security-gateway-vulnerability/). 

 MITRE TTPs: ['T1105 - Ingress Tool Transfer', 'T1027 - Obfuscated Files or Information', 'T1071 - Application Layer Protocol', 'T1059 - Command and Scripting Interpreter'] 

 Impact: The exact number of impacted devices or financial losses is not mentioned. *More than fifty thousand devices using Barracuda ESG are exposed to the vulnerability* (https://teamt5.org/en/posts/cve-2023-2868-barracuda-email-security-gateway-vulnerability/). 

 Mitigation: ['Maintain up-to-date antivirus signatures and engines.', 'Keep operating system patches up-to-date.', 'Disable File and Printer sharing services or use strong passwords/AD authentication if necessary.', "Restrict users' ability to install and run unwanted software applications.", 'Enforce a strong password policy and implement regular password changes.', 'Exercise caution with email attachments, even if the sender appears known.', 'Enable a personal firewall on workstations, configured to deny unsolicited connection requests.', 'Disable unnecessary services on workstations and servers.', 'Scan for and remove suspicious email attachments; ensure the scanned attachment matches its true file type.', "Monitor users' web browsing habits and restrict access to sites with unfavorable content.", 'Exercise caution when using removable media.', 'Scan all software downloaded from the Internet before executing.', 'Maintain situational awareness of the latest threats and implement appropriate Access Control Lists (ACLs).', '*Barracuda recommends a full replacement of the impacted ESG regardless of the patch version* (https://teamt5.org/en/posts/cve-2023-2868-barracuda-email-security-gateway-vulnerability/).', '*Barracuda began releasing containment and remediation patches on May 21, 2023* (https://cloud.google.com/blog/topics/threat-intelligence/barracuda-esg-exploited-globally).', '*The FBI advises immediate replacement of compromised ESG appliances* (https://www.tenable.com/blog/cve-2023-2868-barracuda-and-fbi-recommend-replacing-email-security-gateway-esg-devices).', '*Rotate any credentials connected to the ESG appliance* (https://www.rapid7.com/blog/post/2023/06/08/etr-cve-2023-2868-total-compromise-of-physical-barracuda-esg-appliances/).']
