# Ransomware Spotlight Magniber

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Magniber Ransomware Attack 

 Root cause: The root cause behind the incident includes multiple vulnerabilities exploited by the Magniber ransomware. These include: CVE-2022-44698: Zero-day vulnerability to bypass Mark-of-the-Web (MOTW) security warnings; CVE-2021-26411, CVE-2021-40444, and CVE-2021-34527 (PrintNightmare): Exploited for initial access; Other vulnerabilities like CVE-2016-0189, CVE-2018-8174, CVE-2019-1367, CVE-2020-0968, and *CVE-2023-24880* (https://www.picussecurity.com/resource/resource/blog/cve-2023-24880-vulnerability-exploited-by-magniber-ransomware-group). 

 Threat Actor/group/campaign: Magniber ransomware operators (likely part of a Ransomware-as-a-Service (RaaS) model) *financially motivated threat actors* (https://blog.google/threat-analysis-group/magniber-ransomware-actors-used-a-variant-of-microsoft-smartscreen-bypass/). 

 Organization/industry/location: The blog mentions multiple industries being targeted, including education, government, manufacturing, healthcare, and technology. Initially, it mainly targeted Asian countries, but has since expanded globally, affecting countries such as Taiwan, South Korea, Australia, Turkey, and Japan *with over 100,000 downloads since January 2023* (https://blog.google/threat-analysis-group/magniber-ransomware-actors-used-a-variant-of-microsoft-smartscreen-bypass/). 

 Start date – End date: The attack has been ongoing since its initial detection in 2017, resurfaced in 2021, and continues to operate as of the latest data from 2022. 

 MITRE TTPs: T1190 - Exploit Public-Facing Application; T1204 - User Execution; T1059.003 - Command and Scripting Interpreter: Windows Command Shell; T1047 - Windows Management Instrumentation; T1059.007 - Command and Scripting Interpreter: JavaScript; T1218.010 - Signed Binary Proxy Execution: Regsvr32; T1055.003 - Process Injection: Thread Execution Hijacking; T1140 - Deobfuscate/Decode Files or Information; T1112 - Modify Registry; T1218.007 - System Binary Proxy Execution: Msiexec; T1218.002 - System Binary Proxy Execution: Control Panel; T1036.005 - Masquerading: Match Legitimate Name or Location; T1620 - Reflective Code Loading; T1553.005 - Subvert Trust Controls: Mark-of-the-Web Bypass; T1083 - File and Directory Discovery; T1135 - Network Share Discovery; T1057 - Process Discovery; T1082 - System Information Discovery; T1071.001 - Application Layer Protocol: Web Protocols; T1490 - Inhibit System Recovery; T1486 - Data Encrypted for Impact; T1608.005 - Stage Capabilities: Link Target. 

 Impact: Thousands of attempted attacks and infections, with a notable spike of 1,482 detections in September 2022, and hundreds of attacks in other months. The exact financial impact and number of devices affected were not specified.
