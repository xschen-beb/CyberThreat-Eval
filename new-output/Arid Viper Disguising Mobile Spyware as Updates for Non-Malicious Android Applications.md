# Arid Viper Disguising Mobile Spyware as Updates for Non-Malicious Android Applications

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Arid Viper Mobile Spyware Campaign 

 Root cause: The root cause behind the incident includes the exploitation of legitimate application names and shared project resources on the Firebase platform to disguise malware as updates for non-malicious Android applications. The attackers leveraged the overlap in Firebase project credentials and API keys to deploy their malicious APKs. 

 Threat Actor/group/campaign: Arid Viper advanced persistent threat (APT) group with *Hamas-aligned interests* (https://www.sentinelone.com/labs/arid-viper-apts-nest-of-spyc23-malware-continues-to-target-android-devices/). 

 Organization/industry/location: Targeted Arabic-speaking Android users, particularly in regions with Arabic-speaking populations and specific areas such as *Egypt and Palestine* (https://www.welivesecurity.com/en/eset-research/arid-viper-poisons-android-apps-with-aridspy/#:~:text=In%20August%202023%20we%20logged,by%20the%20initial%2C%20trojanized%20app.). 

 Start date – End date: The campaign has been active since at least April 2022. 

 MITRE TTPs: ['T1071.001: Application Layer Protocol - Web Protocols', 'T1071.004: Application Layer Protocol - DNS', 'T1105: Ingress Tool Transfer', 'T1056.001: Input Capture - Keylogging', 'T1056.002: Input Capture - GUI Input Capture', 'T1056.004: Input Capture - Credential API Hooking', 'T1111: Two-Factor Authentication Interception', 'T1082: System Information Discovery', 'T1012: Query Registry', 'T1083: File and Directory Discovery', 'T1124: System Time Discovery', 'T1129: Shared Modules', 'T1203: Exploitation for Client Execution'] 

 Impact: Potentially thousands of Android devices affected, with significant data exfiltration including contacts, call logs, SMS messages, and other sensitive information. Financial and personal data security impacts are substantial, but exact numbers are not provided. 

 Mitigation: ['Regularly update and patch Android devices and applications.', 'Avoid downloading applications from unofficial sources or links shared via social media or messaging apps.', 'Employ endpoint protection solutions such as Cisco Secure Endpoint to detect and block malicious activities.', 'Use multi-factor authentication (MFA) to add an extra layer of security.', 'Regularly monitor and review application permissions on Android devices.', 'Educate users about the risks of downloading applications from untrusted sources.']
