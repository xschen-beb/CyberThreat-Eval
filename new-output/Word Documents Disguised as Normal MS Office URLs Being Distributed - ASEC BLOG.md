# Word Documents Disguised as Normal MS Office URLs Being Distributed - ASEC BLOG

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Word Documents Disguised as Normal MS Office URLs Being Distributed 

 Root cause: The root cause is the use of Template Injection in Word documents, where malicious URLs are cleverly disguised to resemble legitimate MS Office URLs, exploiting user trust and similar URL appearances to deceive users. *Template Injection in settings.xml.rels is used* (https://asec.ahnlab.com/jp/42683/). This technique evades security tools by using a popular *Highly Evasive Adaptive Threat (HEAT)* technique, and Legacy URL Reputation Evasion (LURE), wherein attackers use websites categorized as having a good reputation by web filters to deliver malware * (https://www.menlosecurity.com/blog/isolation-a-vaccine-for-template-injection-attacks). Additionally, attackers can employ *HTML smuggling* and *Clickjacking in HTML* to further bypass security measures * (https://www.senturean.com/posts/21_03_16_ways_of_phishing_01/). 

 Threat Actor/group/campaign: The blog does not specify the exact threat actor but mentions the malware as 'Downloader/DOC.Kimsuky,' suggesting the involvement of the Kimsuky group, known for targeting South Korean entities. The document also mentions the use of *Empire and Phishery frameworks to create weaponized template injection documents* (https://www.menlosecurity.com/blog/isolation-a-vaccine-for-template-injection-attacks). 

 Organization/industry/location: The targets include specialists in diplomatic security, with filenames related to North Korea, China, surveys, or diplomatic security, suggesting victims in the diplomatic and security sectors, particularly in South Korea. *The malicious documents are being distributed through KaKaoTalk group chats* (https://asec.ahnlab.com/ko/42233/). Additionally, *hijacking existing email thread conversations* is another infection vector used by adversaries to distribute these weaponized documents * (https://www.menlosecurity.com/blog/isolation-a-vaccine-for-template-injection-attacks). 

 Start date – End date: The attack was ongoing around November 2022, as indicated by the publication date of the blog post (Nov 17, 2022). 

 MITRE TTPs: ['T1203 - Exploitation for Client Execution: Exploiting vulnerabilities in Word documents.', 'T1071.001 - Application Layer Protocol: Web Protocols: Using URLs to download and execute malicious templates.', 'T1193 - Spearphishing Attachment: Distributing malicious documents through phishing.'] 

 Impact: The precise impact in terms of the number of devices or financial losses is not mentioned. However, given the nature of the targets (diplomatic security specialists), the impact could involve significant breaches of sensitive information. The technique is noteworthy for evading security tools and solutions using *Living off the Land (LotL)* attacks, where legitimate software is used to perform malicious actions * (https://www.menlosecurity.com/blog/isolation-a-vaccine-for-template-injection-attacks). The use of *macro-enabled DOTM templates* and *registry key modification* techniques further enhances the attack's stealth * (https://www.senturean.com/posts/21_03_16_ways_of_phishing_01/). 

 Mitigation: ['Update antivirus software (e.g., V3) to the latest version to detect and block the malicious documents.', 'Avoid opening document files from unknown sources.', 'Confirm the legitimacy of files even if they are forwarded from credible users.', 'Implement email filtering and attachment scanning to detect and block malicious attachments.', 'Educate users on recognizing phishing attempts and suspicious URLs.']
