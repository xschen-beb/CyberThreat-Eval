# Bad Magic New APT Found in the Area of Russo-Ukrainian Conflict

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Bad Magic: New APT Found in the Area of Russo-Ukrainian Conflict 

 Root cause: The root cause includes: - Use of malicious LNK files with double extensions (e.g., .pdf.lnk) leading to malware infection upon opening. - The infection chain involves downloading a malicious MSI file that acts as a dropper package, containing an encrypted payload and a decoy document. - The dropper uses a VBS script to execute an embedded PowerShell script that decrypts the next stage malware. - The backdoor, named PowerMagic, leverages cloud storage services like OneDrive and Dropbox for command and control (C&C) communication. *Additionally, the CloudWizard framework builds on CommonMagic with modules for keylogging, microphone recording, USB data stealing, and more* (https://www.normcyber.com/bulletins/norm-threat-bulletin-31st-may-2023/). 

 Threat Actor/group/campaign: The specific threat actor behind the Bad Magic campaign is not yet attributed to any known group. The campaign is still active, and ongoing investigations may reveal more details *including the potential involvement of a new threat group* (https://www.broadcom.com/support/security-center/protection-bulletin/new-threat-group-leveraging-powermagic-backdoor-and-commonmagic-framework). *Characteristics of CloudWizard match previous APT campaigns in Ukraine, such as Operation Groundbait and Operation BugDrop* (https://www.normcyber.com/bulletins/norm-threat-bulletin-31st-may-2023/). 

 Organization/industry/location: The victims targeted by this campaign include government, agriculture, and transportation organizations located in the Donetsk, Lugansk, and Crimea regions. *Kaspersky researchers* (https://social.cyware.com/news/new-apt-found-actively-using-powermagic-backdoor-and-commonmagic-framework-b49856b5) identified an active infection. *New victims have also been found in diplomatic and research organizations in central and western Ukraine* (https://www.normcyber.com/bulletins/norm-threat-bulletin-31st-may-2023/). *Additionally, administrative organizations were targeted* (https://www.infosecurity-magazine.com/news/commonmagic-targets-russo/). 

 Start date – End date: The campaign was identified in October 2022 *by Kaspersky researchers* (https://social.cyware.com/news/new-apt-found-actively-using-powermagic-backdoor-and-commonmagic-framework-b49856b5). The blog was published on March 21, 2023, indicating ongoing activity. *The group has been active since at least September 2021* (https://www.infosecurity-magazine.com/news/commonmagic-targets-russo/). 

 MITRE TTPs: - T1071.001: Application Layer Protocol: Web Protocols - T1059.001: Command and Scripting Interpreter: PowerShell - T1204.002: User Execution: Malicious File - T1566.002: Phishing: Spearphishing Link - T1070.004: Indicator Removal on Host: File Deletion - T1090: Proxy 

 Impact: The exact number of records leaked or devices affected is not specified. The impact includes unauthorized access to sensitive information and potential disruption of services. 

 Mitigation: 1. **User Awareness Training:** Educate users about the risks of opening unsolicited email attachments and clicking on suspicious links. 2. **Email Filtering:** Implement advanced email filtering to detect and block malicious attachments and links. 3. **Endpoint Protection:** Use endpoint protection solutions with capabilities to detect and block malicious scripts and executables. 4. **Cloud Storage Security:** Monitor and restrict the use of cloud storage services for unauthorized data exfiltration. 5. **Regular Patching:** Ensure that all systems and software are regularly updated with the latest security patches. 6. **Network Segmentation:** Implement network segmentation to limit the spread of malware within the organization. 7. **Incident Response Plan:** Develop and regularly update an incident response plan to quickly address and mitigate security incidents. 

 Detection Signature: - **Service:** Windows Installer (msiexec.exe) - **Port:** N/A (Local execution) - **Severity:** Critical - **Incident:** Bad Magic - **Signature name:** “Malicious MSI File Execution” - **Internal checks:** - **Setting1:** Monitor for execution of msiexec.exe with parameters pointing to external URLs. - **Setting2:** Detect and alert on the creation and execution of LNK files with double extensions. - **Setting3:** Monitor PowerShell script executions that involve decryption and file manipulations. - **External scanning:** - **URL monitoring:** Monitor and block access to malicious URLs (e.g., 185.166.217[.]184).
