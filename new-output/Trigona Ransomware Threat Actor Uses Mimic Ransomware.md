# Trigona Ransomware Threat Actor Uses Mimic Ransomware

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Trigona Ransomware Threat Actor Uses Mimic Ransomware 

 Root Cause: Poorly managed MS-SQL servers with simple account credentials, making them vulnerable to brute force or dictionary attacks. The exploitation of the Bulk Copy Program (BCP) utility in MS-SQL servers during the malware installation process. 

 Threat Actor/Group/Campaign: Trigona ransomware threat actor, potentially the same group behind the Mimic ransomware attacks. *Financially motivated Turkish Hackers have also been involved, particularly in the RE#TURGENCE campaign* (https://www.securonix.com/blog/securonix-threat-research-security-advisory-new-returgence-attack-campaign-turkish-hackers-target-mssql-servers-to-deliver-domain-wide-mimic-ransomware/). 

 Organization/Industry/Location: Not specified, but the targets are poorly managed MS-SQL servers, likely in various organizations in the US, EU, and LATAM regions. 

 Start date – End date: The attack was identified in early January 2024 and continued through mid-January 2024. 

 MITRE TTPs: ['T1078: Valid Accounts', 'T1105: Ingress Tool Transfer', 'T1059: Command and Scripting Interpreter', 'T1003: Credential Dumping', 'T1562: Impair Defenses', 'T1021: Remote Services'] 

 Impact: The exact number of records or financial losses is not specified, but the ransomware encrypts files and extorts sensitive information, potentially impacting entire networks.
