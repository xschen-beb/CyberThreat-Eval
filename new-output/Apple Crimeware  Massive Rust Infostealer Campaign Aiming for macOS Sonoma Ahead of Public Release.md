# Apple Crimeware  Massive Rust Infostealer Campaign Aiming for macOS Sonoma Ahead of Public Release

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Realst Infostealer Campaign 

 Root cause: The primary root cause behind the Realst Infostealer campaign is the use of fake blockchain games to distribute malware. The malicious software is delivered through websites advertising these fake games, which include Mach-O samples targeting macOS systems. The malware takes advantage of social engineering tactics, such as direct messages through social media, to lure victims into downloading and executing the malicious software. *The campaign also involves the distribution of RedLine Stealer* (https://iamdeadlyz.gitbook.io/malware-research/july-2023/fake-blockchain-games-deliver-redline-stealer-and-realst-stealer-a-new-macos-infostealer-malware#realst-stealer-macos). *Some versions of the malware are packaged in Electron apps and native macOS applications* (https://www.tanium.com/blog/cti-roundup-realst-malware-targets-macos-infostealer-malware-sees-exponential-growth/). *The malware is written in the Rust programming language, known for its high performance and memory safety* (https://www.hokanews.com/2023/07/breaking-rust-based-realst-infostealer.html). *The fake blockchain games used include Brawl Earth, WildWorld, Dawnland, Destruction, Olymp of Reptiles, and SaintLegend* (https://www.secureblink.com/cyber-security-news/realst-stealthy-mac-os-infostealer-from-fake-blockchain-games-exposed). *It is distributed through PKG installers and DMG disks containing malicious Mach-O files* (https://www.techradar.com/pro/new-macos-malware-is-after-your-data-and-your-crypto-heres-how-to-stay-safe). 

 Threat Actor/group/campaign: The exact threat actor(s) behind this campaign is not explicitly identified, but the campaign is linked to earlier PearlLand infostealer activities and *PureLand, which is associated with sandbox malspam* (https://iamdeadlyz.gitbook.io/malware-research/july-2023/fake-blockchain-games-deliver-redline-stealer-and-realst-stealer-a-new-macos-infostealer-malware#realst-stealer-macos). *Our meticulous analysis revealed 16 variants divided into four major families: A, B, C, and D* (https://www.secureblink.com/cyber-security-news/realst-stealthy-mac-os-infostealer-from-fake-blockchain-games-exposed). *Some samples were signed using valid Apple Developer IDs to bypass detection* (https://www.techradar.com/pro/new-macos-malware-is-after-your-data-and-your-crypto-heres-how-to-stay-safe). 

 Organization/industry/location: *The campaign targets macOS users, particularly those with interests in blockchain games and cryptocurrency*. *It also specifically prepares for macOS 14 Sonoma* (https://www.tanium.com/blog/cti-roundup-realst-malware-targets-macos-infostealer-malware-sees-exponential-growth/). 

 Start date – End date: The blog post references research from July 2023, indicating the campaign was active around this time. 

 MITRE TTPs: ['T1033: System Owner/User Discovery (whoami)', 'T1059: Command and Scripting Interpreter (osascript)', 'T1070.004: File Deletion (rmdir)', 'T1082: System Information Discovery (sw_vers)', 'T1083: File and Directory Discovery (dirname, basename)', 'T1553: Bypass or Subvert Trust Controls (xattr)', 'T1620: Reflective Code Loading (execv, fork)', 'T1562: Disable or Modify Tools (sleep, waitpid)', 'T1639.001: Exfiltration Over Unencrypted Non-C2 Protocol (tcp, http)'] 

 Impact: The campaign has compromised the security of macOS users by stealing sensitive data, including browser data, stored passwords, and cryptocurrency wallet information. The exact number of affected users is not specified, but the distribution of multiple fake games suggests a potentially significant impact. *The malware also exfiltrates data to Telegram channels* (https://www.tanium.com/blog/cti-roundup-realst-malware-targets-macos-infostealer-malware-sees-exponential-growth/). *It operates very stealthily and removes digital traces to evade detection* (https://www.hokanews.com/2023/07/breaking-rust-based-realst-infostealer.html). *Telegram is a target along with Chrome, Firefox, Opera, Brave, and Vivaldi browsers* (https://www.techradar.com/pro/new-macos-malware-is-after-your-data-and-your-crypto-heres-how-to-stay-safe).
