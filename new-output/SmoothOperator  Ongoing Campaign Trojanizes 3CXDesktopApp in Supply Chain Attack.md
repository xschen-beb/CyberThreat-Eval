# SmoothOperator  Ongoing Campaign Trojanizes 3CXDesktopApp in Supply Chain Attack

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: 3CX SmoothOperator Supply Chain Attack 

 Root cause: The root cause includes the compromise of the 3CXDesktopApp software, trojanized with malware. Attackers infiltrated the supply chain introducing malicious code into legitimate application binaries. The compromised code included a trojanized `libffmpeg.dylib` library in the macOS app and a multi-stage attack chain in the Windows app. The attackers employed a *DLL side-loading technique* (https://www.uptycs.com/blog/3cx-supply-chain-attack). *The macOS variant was validly signed by the 3CX developer and notarized by Apple* (https://objective-see.org/blog/blog_0x73.html). 

 Threat Actor/group/campaign: The campaign is linked to the Lazarus malware family per Mandiant. However, the exact threat actor behind this specific campaign is still under investigation, though CrowdStrike suspects LABYRINTH CHOLLIMA *(https://research.kudelskisecurity.com/2023/03/30/3cx-supply-chain-attack-smoothoperator/)*. *SentinelOne researchers also tracked the activity under the name SmoothOperator* (https://thehackernews.com/2023/03/3cx-desktop-app-targeted-in-supply.html). 

 Organization/industry/location: The incident targeted 3CX, a business communications software company. Victims include 3CX's broad customer base in industries like automotive, food & beverage, hospitality, MSPs, and manufacturing. *3CX claims to have more than 600,000 customers and 12 million users in 190 countries, including well-known names like American Express, BMW, Honda, Ikea, Pepsi, and Toyota* (https://thehackernews.com/2023/03/3cx-desktop-app-targeted-in-supply.html). 

 Start date – End date: The attack was detected on March 22, 2023, with analysis and updates continuing through to at least April 24, 2023. 

 MITRE TTPs: ['T1195.002: Supply Chain Compromise', 'T1059.001: Command and Scripting Interpreter: PowerShell', 'T1055.002: Process Injection: Portable Executable Injection', 'T1071.001: Application Layer Protocol: Web Protocols', 'T1518: Software Discovery', 'T1070.004: Indicator Removal on Host: File Deletion', 'T1083: File and Directory Discovery'] 

 Impact: Potential compromise of up to 600,000 customer companies with 12 million daily users relying on 3CX's software.
