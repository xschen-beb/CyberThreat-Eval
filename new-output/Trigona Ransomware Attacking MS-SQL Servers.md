# Trigona Ransomware Attacking MS-SQL Servers

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Trigona Ransomware Attacking MS-SQL Servers 

 Root cause: Poorly managed MS-SQL servers with simple account credentials and exposure to external connections. This vulnerability allows threat actors to perform brute force or dictionary attacks to gain unauthorized access. 

 Threat Actor/group/campaign: Trigona ransomware operators. The report also mentioned the use of CLR SqlShell malware, *CryptBot malware* (https://global.ahnlab.com/global/upload/download/asecreport/ASEC%20REPORT_vol.109_ENG.pdf), and the exploitation of *Windows Secondary Logon Service* (https://heimdalsecurity.com/blog/trigona-ransomware-deployed-through-vulnerable-microsoft-sql-servers/). *Malware executed as svcservice.exe service* (https://www.bleepingcomputer.com/news/security/microsoft-sql-servers-hacked-to-deploy-trigona-ransomware/#:~:text=%22CLR%20Shell%20is%20a%20type,web%20servers%2C%22%20AhnLab%20says.). 

 Organization/industry/location: *Manufacturing sector* (https://unit42.paloaltonetworks.com/trigona-ransomware-update/). 

 Start date – End date: *Discovered in October 2022* and *active during December 2022* (https://unit42.paloaltonetworks.com/trigona-ransomware-update/). 

 MITRE TTPs: ['T1078: Valid Accounts', 'T1210: Exploitation of Remote Services', 'T1059: Command and Scripting Interpreter', 'T1074: Data Staged', 'T1486: Data Encrypted for Impact'] 

 Impact: The specific number of records or financial losses is not mentioned in the report. 

 Mitigation: {'Secure MS-SQL Servers': ['Ensure MS-SQL servers are not exposed to external connections unnecessarily.', 'Use strong, complex passwords and change them periodically.', 'Implement account lockout policies to prevent brute force attacks.', 'Regularly update and patch MS-SQL servers and underlying OS to mitigate known vulnerabilities. *Consider CVE-2022-26809* (https://global.ahnlab.com/global/upload/download/asecreport/ASEC%20REPORT_vol.109_ENG.pdf).'], 'Use Security Tools': ['Deploy anti-malware solutions like V3 and keep them updated.', 'Use firewalls to restrict access to database servers from the outside.', 'Implement network monitoring to detect unusual activities.'], 'Privilege Management': ['Restrict high privileges on MS-SQL servers to the minimum necessary.', 'Regularly review and audit user accounts and their privileges.'], 'Backup and Recovery': ['Regularly backup data and ensure backups are stored securely and offline.', 'Test recovery plans to ensure data can be restored quickly in the event of an attack.', '*Maintain offline backups and ensure all backup data is encrypted and immutable* (https://www.csk.gov.in/alerts/Trigona_ransomware.html).', '*Implement multi-factor authentication for all services and remove unnecessary access to administrative shares* (https://www.csk.gov.in/alerts/Trigona_ransomware.html).']}

 By implementing these mitigations and detection mechanisms, organizations can better protect their MS-SQL servers against similar ransomware attacks. *Trigona’s ransom notes are unique as HTML Applications with embedded JavaScript* (https://unit42.paloaltonetworks.com/trigona-ransomware-update/) and *ransom payments are accepted in Monero cryptocurrency* (https://heimdalsecurity.com/blog/trigona-ransomware-deployed-through-vulnerable-microsoft-sql-servers/). Trigona ransomware persists through reboots by configuring autorun keys and renames encrypted files with the *._locked extension* (https://heimdalsecurity.com/blog/trigona-ransomware-deployed-through-vulnerable-microsoft-sql-servers/), with the malware executed as *svchost.exe* (https://heimdalsecurity.com/blog/trigona-ransomware-deployed-through-vulnerable-microsoft-sql-servers/). *System recovery is disabled and Windows Volume Shadow copies deleted before encryption* (https://www.bleepingcomputer.com/news/security/microsoft-sql-servers-hacked-to-deploy-trigona-ransomware/#:~:text=%22CLR%20Shell%20is%20a%20type,web%20servers%2C%22%20AhnLab%20says.). *Ransom notes named 'how_to_decrypt.hta' are created in each folder with attack details* (https://www.bleepingcomputer.com/news/security/microsoft-sql-servers-hacked-to-deploy-trigona-ransomware/#:~:text=%22CLR%20Shell%20is%20a%20type,web%20servers%2C%22%20AhnLab%20says.). *Campaign ID and victim ID embedded in locked files* (https://www.bleepingcomputer.com/news/security/microsoft-sql-servers-hacked-to-deploy-trigona-ransomware/#:~:text=%22CLR%20Shell%20is%20a%20type,web%20servers%2C%22%20AhnLab%20says.). *Uses AES algorithm for encryption* (https://www.csk.gov.in/alerts/Trigona_ransomware.html) *and communicates through TOR* (https://www.csk.gov.in/alerts/Trigona_ransomware.html).: final_report
