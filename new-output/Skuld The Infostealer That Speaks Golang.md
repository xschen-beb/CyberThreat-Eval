# Skuld The Infostealer That Speaks Golang

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Skuld: The Infostealer that Speaks Golang 

 Root cause: The root cause behind the incident is the usage of unprotected and unmonitored Discord webhooks and Gofile upload services for data exfiltration. The malware also exploits vulnerabilities in applications like Discord and web browsers to steal sensitive information. *Skuld samples are written in Golang 1.20.3, making them more challenging to analyze and reverse engineer* (https://www.trellix.com/blogs/research/skuld-the-infostealer-that-speaks-golang/). *Some samples include a module to steal cryptocurrency assets, believed to be still in development* (https://rhisac.org/threat-intelligence/new-skuld-infostealer-malware-written-in-golang/). *The malware specifically targets Windows devices, enhancing its attack surface* (https://latesthackingnews.com/2023/06/19/new-skuld-malware-targets-windows-to-steal-data/). *Skuld prompts the victim with a fake error message before executing various modules to steal information* (https://www.tanium.com/blog/skuld-malware-steals-discord-data-cyber-threat-intelligence-roundup/). 

 Threat Actor/group/campaign: The attack was carried out by an individual known as 'Deathined,' who has created several social media accounts likely to promote their malware business, including a *deathinews Telegram group* (https://www.trellix.com/blogs/research/skuld-the-infostealer-that-speaks-golang/). 

 Organization/industry/location: The report does not specify a particular organization targeted; the malware appears to affect users globally, especially those on gaming platforms like Discord. *Active against unspecified targets in North America, Europe, and Southeast Asia* (https://rhisac.org/threat-intelligence/new-skuld-infostealer-malware-written-in-golang/). 

 Start date – End date: Initial detection and analysis in April 2023 by *Trellix Advanced Research Center*, with details published by Trellix in June 2023 (https://www.trellix.com/blogs/research/skuld-the-infostealer-that-speaks-golang/).

 Technical Analysis: Skuld samples use a multitude of libraries, some modified to evade detection. Tools like *GoReSym* (https://www.trellix.com/blogs/research/skuld-the-infostealer-that-speaks-golang/) are needed for proper analysis. *The use of Golang to write malware is less common but is increasing in popularity. Golang’s cross-platform compatibility broadens the potential victim pool* (https://rhisac.org/threat-intelligence/new-skuld-infostealer-malware-written-in-golang/). *A YARA rule was provided for hunting Skuld stealer* (https://rhisac.org/threat-intelligence/new-skuld-infostealer-malware-written-in-golang/). *Skuld also performs VM checks to evade detection and utilizes clipper functionalities to hijack cryptocurrency wallet addresses* (https://latesthackingnews.com/2023/06/19/new-skuld-malware-targets-windows-to-steal-data/). *Skuld injects JavaScript code into the discord_desktop_core module and corrupts the file “%APPDATA%\BetterDiscord\data\betterdiscord.asar” to bypass security* (https://www.tanium.com/blog/skuld-malware-steals-discord-data-cyber-threat-intelligence-roundup/). *It also targets backup codes from Discord, replacing the string “api/webhooks” with “ByDeathined”* (https://www.tanium.com/blog/skuld-malware-steals-discord-data-cyber-threat-intelligence-roundup/). *If Skuld detects it is being monitored, it terminates its execution* (https://www.tanium.com/blog/skuld-malware-steals-discord-data-cyber-threat-intelligence-roundup/).
