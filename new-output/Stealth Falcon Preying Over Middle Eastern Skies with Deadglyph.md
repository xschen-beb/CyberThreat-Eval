# Stealth Falcon Preying Over Middle Eastern Skies with Deadglyph

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Stealth Falcon preying over Middle Eastern skies with Deadglyph 

 Root cause: Misconfigured systems allowed the deployment of a sophisticated backdoor, Deadglyph, leveraging Windows Management Instrumentation (WMI) event subscription for persistence. The backdoor exploits system defense weaknesses using components encrypted with a machine-specific key and obfuscation techniques to avoid detection. *The attack involved a homoglyph attack using Cyrillic 'M' and Greek 'o' in place of Latin characters in 'Microsoft Corporation'* (https://www.darkreading.com/threat-intelligence/stealth-falcon-apt-microsoft-homoglyph-attack). *The initial component is a registry shellcode loader, which loads shellcode from the registry. This extracted shellcode, in turn, loads the native x64 part of the backdoor – the Executor. The Executor subsequently loads the .NET part of the backdoor – the Orchestrator* (https://securityaffairs.com/151298/malware/deadglyph-backdoor-middle-east.html). *Distinctive artifacts like '0xDEADB001' were found within Deadglyph* (https://hackread.com/deadglyph-backdoor-stealth-falcon-apt-middle-east/). *Deadglyph can uninstall itself to minimize detection likelihood* (https://version-2.com/en/2023/10/uae-linked-stealth-falcon-spies-with-sophisticated-new-backdoor-on-its-neighbors-eset-research-discovers/). 

 Threat Actor/group/campaign: Stealth Falcon (also known as Project Raven or FruityArmor), *utilizing tools like the Karma hacking tool* (https://www.reuters.com/investigates/special-report/usa-spying-raven/). *ESET attributes Deadglyph to UAE* (https://version-2.com/en/2023/10/uae-linked-stealth-falcon-spies-with-sophisticated-new-backdoor-on-its-neighbors-eset-research-discovers/). 

 Organization/industry/location: Governmental entity in the Middle East, specifically targeting entities in Qatar and other Middle Eastern regions. *The attack spanned the Anatolian and Arabian peninsulas* (https://www.darkreading.com/threat-intelligence/stealth-falcon-apt-microsoft-homoglyph-attack). 

 Start date – End date: Detected in 2023; specific start and end dates not provided.
