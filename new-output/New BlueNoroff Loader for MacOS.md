# New BlueNoroff Loader for MacOS

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: BlueNoroff macOS Trojan Attack 

 Root cause: The root cause behind the incident is the use of a malicious loader targeting macOS users, distributed via a ZIP archive containing a PDF file. The loader, signed with a valid Apple Developer ID certificate (since revoked), delivered malware dubbed ObjCShellz, a Mach-O universal binary communicating with a domain (swissborgblog) registered on May 31, 2023 *that the company had previously classified as malicious because it was a fake version of the original domain (swissborg.com)* (https://hackread.com/lazarus-bluenoroff-apt-macos-objcshellz-malware/). *A notable aspect is the involvement of a .NET version of RustBucket, using DevExpress libraries to execute malicious payloads on Windows systems* (https://blog.sekoia.io/bluenoroffs-rustbucket-campaign/#:~:text=Bluenoroff's%20gone%20macOS&text=The%20RustBucket%20infection%20chain%20consists,to%20trigger%20the%20malicious%20activity.). *Jamf Threat Labs discovered stage-one malware (0be69bb9836b2a266bfd9a8b93bb412b6e4ce1be) that uses an XOR key for decryption and communicates with the cloud.dnx.capital domain* (https://www.jamf.com/blog/bluenoroff-apt-targets-macos-rustbucket-malware/). 

 Threat Actor/group/campaign: BlueNoroff (linked to Lazarus Group), ongoing campaign known as RustBucket, utilizing ObjCShellz malware. 

 Organization/industry/location: Financial organizations, particularly those related to cryptocurrency, and individuals holding crypto assets. The threat actor has a history of targeting cryptocurrency exchanges, venture capital firms, and banks. 

 Start date – End date: The app was created on October 21, 2023. The blog post is dated December 5, 2023. VirusTotal submissions from Japan and the US were observed in September and October * (https://hackread.com/lazarus-bluenoroff-apt-macos-objcshellz-malware/). *The campaign targets were initially identified in December 2022, with continuous activity observed into 2023* (https://blog.sekoia.io/bluenoroffs-rustbucket-campaign/#:~:text=Bluenoroff's%20gone%20macOS&text=The%20RustBucket%20infection%20chain%20consists,to%20trigger%20the%20malicious%20activity.). 

 MITRE TTPs: ['T1203 (Exploitation for Client Execution)', 'T1071 (Application Layer Protocol)', 'T1083 (File and Directory Discovery)', 'T1059.001 (Command and Scripting Interpreter: PowerShell)', 'T1027 (Obfuscated Files or Information)'] 

 Impact: The exact number of devices or financial losses is not specified. It involves the potential compromise of financial data and cryptocurrency assets. ObjCShellz operates as a remote shell, executing commands and retrieving system information.
