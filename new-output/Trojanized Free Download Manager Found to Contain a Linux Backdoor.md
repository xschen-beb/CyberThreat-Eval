# Trojanized Free Download Manager Found to Contain a Linux Backdoor

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: Free Download Manager Backdoored – A Possible Supply Chain Attack on Linux Machines 

 Root cause: The root cause behind the incident was a malicious Debian repository. An infected Debian package for Free Download Manager was distributed via a subdomain (deb.fdmpkg[.]org). The package contained malicious scripts that installed a backdoor and a stealer on the victim's system. *The cybersecurity firm Kaspersky Lab identified the compromise* (https://www.freedownloadmanager.org/blog/?p=664). *The malware established a reverse shell to a C2 server and the crond backdoor launched the /var/tmp/bs executable for SSL/TCP communications* (https://hackread.com/free-download-site-pushed-linux-password-stealer/). *Kaspersky experts discovered the attackers used YouTube installation guides to spread the malware* (https://securitybrief.com.au/story/kaspersky-uncovers-3-year-old-supply-chain-attack-campaign). *Comments in Russian and Ukrainian, including information about improvements made to the malware, were found in the postinst script* (https://securityaffairs.com/150851/malware/free-download-manager-supply-chain-attack.html). 

 Threat Actor/group/campaign: Not explicitly named in the report. The backdoor is a modified version of the Bew backdoor, known since 2013. *A Ukrainian hacker group exploited a script vulnerability* (https://www.freedownloadmanager.org/blog/?p=664). *The attackers utilized digital fingerprints to selectively infect users* (https://securitybrief.com.au/story/kaspersky-uncovers-3-year-old-supply-chain-attack-campaign). *The Bash stealer was analyzed by Yoroi in 2019* (https://hackread.com/free-download-site-pushed-linux-password-stealer/). 

 Organization/industry/location: Linux users globally, including in Brazil, China, Saudi Arabia, and Russia. 

 Start date – End date: The malicious package was distributed from at least January 2020 to 2022. *The vulnerability was unknowingly resolved during a site update in 2022* (https://www.freedownloadmanager.org/blog/?p=664). 

 MITRE TTPs: ['T1071.004 (Application Layer Protocol: DNS)', 'T1203 (Exploitation for Client Execution)', 'T1059.004 (Command and Scripting Interpreter: Unix Shell)', 'T1078 (Valid Accounts)', 'T1053.003 (Scheduled Task/Job: Cron)'] 

 Impact: The exact number of devices impacted is unclear; the campaign has victims in multiple countries. *Less than 0.1% of users were affected* (https://www.freedownloadmanager.org/blog/?p=664). *The malware collected various types of data, including system information, browsing history, saved passwords, cryptocurrency wallet data, and cloud services credentials* (https://www.bleepingcomputer.com/news/security/free-download-manager-site-redirected-linux-users-to-malware-for-years/). 

 Mitigation: ['Ensure that software is downloaded from verified and trusted sources.', 'Regularly audit and monitor systems for unusual cron jobs or other signs of modifications.', 'Implement security solutions that can detect and prevent malware on Linux systems.', 'Verify the integrity of downloaded packages using checksums.', 'Regularly update and patch systems to avoid exploitation of known vulnerabilities. *Utilize the provided bash script for malware check* (https://www.freedownloadmanager.org/blog/?p=664).', '*Refer to the FDM team statement for further guidance* (https://www.bleepingcomputer.com/news/security/free-download-manager-site-redirected-linux-users-to-malware-for-years/). *Security expert Georgy Kucherin emphasizes the need for robust Linux protection measures* (https://securitybrief.com.au/story/kaspersky-uncovers-3-year-old-supply-chain-attack-campaign). *The Free Download Manager team apologized to users and urged them to scan their systems and update passwords* (https://hackread.com/free-download-site-pushed-linux-password-stealer/).']
