# Fake ChatGPT Chrome Extension Hijacking Facebook Accounts for Malicious Advertising

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: FakeGPT Chrome Extension Stealing Facebook Ad Accounts 

 Root cause: The incident was caused by installing a malicious Chrome extension named 'Quick access to Chat GPT' that hijacks Facebook accounts and installs hidden account backdoors. The extension abuses Facebook’s Graph API, Chrome’s `declarativeNetRequest` API, and a malicious Facebook application to manipulate request headers and perform actions on behalf of users, granting super-admin permissions. *This variant is based on an open-source product and uses Google sponsored search results for propagation* (https://labs.guard.io/fakegpt-2-open-source-turned-malicious-in-another-variant-of-the-facebook-account-stealer-d00ef9883d61). *The extension, named 'Chat GPT for Google,' can steal Facebook session cookies, encrypt them with AES, and send them to the attacker's server* (https://social.cyware.com/news/new-fakegpt-chrome-extension-hijacks-facebook-accounts-b0146898). *The SOC202 alert identified the malicious extension on Samuel's workstation through endpoint logs and Microsoft Defender* (https://stumblesec.medium.com/letsdefend-soc202-fakegpt-malicious-chrome-extension-investigation-walkthrough-c72d2a6ab95e). *The system named Samuel, with IP address 172.16.17.173, executed the extension with Process ID 5756* (https://0xelshazly.github.io/security%20alert/letsdefend/SOC202-FakeGPT/). 

 Threat Actor/group/campaign: Specific threat actor(s) not named, responsible for creating and propagating the FakeGPT Chrome extension. 

 Organization/industry/location: Individual Facebook users, especially those with high-profile business accounts, were targeted. 

 Start date – End date: The campaign started in early February 2023 and was detected on March 3, 2023. The extension was removed from the Chrome store on March 9, 2023. *The new variant started propagating on March 14, 2023 and was removed on March 22, 2023* (https://labs.guard.io/fakegpt-2-open-source-turned-malicious-in-another-variant-of-the-facebook-account-stealer-d00ef9883d61). 

 MITRE TTPs: ['T1203: Exploitation for Client Execution', 'T1071: Application Layer Protocol', 'T1090: Connection Proxy', 'T1078: Valid Accounts', 'T1074: Data Staged', 'T1003: Credential Dumping'] 

 Impact: Thousands of daily installs leading to the hijacking of Facebook ad accounts, with over 2000 users installing the extension daily. Financial losses include unauthorized spending on Facebook ads. The extension's worm-like propagation exacerbates the spread. *Hijacked accounts were used for ISIS propaganda and other malicious activities* (https://labs.guard.io/fakegpt-2-open-source-turned-malicious-in-another-variant-of-the-facebook-account-stealer-d00ef9883d61). *The extension received over 9,000 downloads before removal* (https://social.cyware.com/news/new-fakegpt-chrome-extension-hijacks-facebook-accounts-b0146898). *The extension was confirmed malicious through analysis of the file hash: 7421f9abe5e618a0d517861f4709df53292a5f137053a227bfb4eb8e152a4669* (https://stumblesec.medium.com/letsdefend-soc202-fakegpt-malicious-chrome-extension-investigation-walkthrough-c72d2a6ab95e). *The identified connections to chatgptforgoogle.pro highlight the need for immediate action* (https://0xelshazly.github.io/security%20alert/letsdefend/SOC202-FakeGPT/). 

 Mitigation: ['**Uninstall the Malicious Extension**: Immediately remove any suspicious extensions from your browser.', '**Change Facebook Passwords**: Reset your Facebook password and enable two-factor authentication.', '**Review Account Permissions**: Check and remove any unfamiliar apps or services with access to your Facebook account.', '**Update Browser and Security Software**: Ensure your browser and any security software are up to date.', '**Educate Users**: Inform users about the dangers of installing unverified extensions and the importance of scrutinizing permissions.']
