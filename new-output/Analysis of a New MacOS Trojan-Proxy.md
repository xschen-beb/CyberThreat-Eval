# Analysis of a New MacOS Trojan-Proxy

# Enriched Doc (enrihcments marked with *content*(link)): 
 Incident: New macOS Trojan-Proxy piggybacking on cracked software. 

 Root cause: The root cause behind the incident is the distribution of cracked software from unauthorized websites, which includes a malicious post-installation script that installs a Trojan-Proxy. This Trojan utilizes the macOS Installer utility to execute scripts that replace legitimate system files with malicious ones. The malware, *Activator.app, uses a Python 3.9.6 installer* and an obsolete function, AuthorizationExecuteWithPrivileges, to gain admin privileges (https://www.infosecurity-magazine.com/news/macos-malware-targets-cracked-apps/). 

 Threat Actor/group/campaign: Not specified in the document. 

 Organization/industry/location: Individual users of macOS, especially *macOS Ventura 13.6* and newer, who download cracked software from unauthorized sources (https://www.infosecurity-magazine.com/news/macos-malware-targets-cracked-apps/). 

 Start date – End date: The earliest version of the Trojan was uploaded to VirusTotal on April 28, 2023.

 Impact: The exact number of devices impacted or financial losses is not specified. However, the Trojan-Proxy can be used to build a proxy server network, launch attacks, or perform criminal activities on behalf of the victim.
