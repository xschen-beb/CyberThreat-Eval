#### Incident: TA866/Asylum Ambuscade Activity Analysis 

#### Root cause 
 The attack vectors primarily include malspam, malvertising, and the use of Traffic Distribution Systems (TDS) such as 404 TDS. Misconfigured email servers and lack of proper web filtering allowed the delivery of malicious content. *WarmCookie/BadSpace malware, malicious JavaScript downloaders, email attachments, and CSharp-Streamer-RAT have also been used as initial access and persistence tools by TA866* (https://www.infosecurity-magazine.com/news/malware-warmcookie-users-malicious/). 

#### Threat actor/group/campaign 
 TA866, also known as Asylum Ambuscade. 

#### Organization/industry/location 
 The primary targets were organizations in the United States, Canada, United Kingdom, Germany, Italy, Austria, and the Netherlands, spanning sectors such as manufacturing, government, and financial services. 

#### Start date – End date 
 The activity has been ongoing since at least 2020 and continues to the present, with the latest observations noted in 2024. 

#### MITRE TTPs 
 ['Reconnaissance: T1589.002', 'Resource Development: T1586.002, T1608.006, T2583.008', 'Initial Access: T1566, T1566.001, T1566.002', 'Execution: T1059.001, T1059.003, T1047', 'Persistence: T1574.002', 'Defense Evasion: T1218.007', 'Discovery: T1069.002, T1016, T1482, T1018, T1057, T1007, T1518.001, T1124, T1082, T1033', 'Command and Control: T1105, T1219, T1071.001'] 

#### Impact 
 The exact number of impacted records is not specified, but the sectors affected include manufacturing, government, and financial services across multiple countries. *WarmCookie enables adversaries to deploy additional malware like Cobalt Strike and supports command execution, screenshot capture, and payload deployment* (https://www.infosecurity-magazine.com/news/malware-warmcookie-users-malicious/).

#### Incident: Malware Analysis - Divulge Stealer, Dedsec Stealer, and Duck Stealer 

#### Root cause 
 The root cause behind the incident includes the utilization of open-source repositories like GitHub to propagate malware, the use of platforms like Discord and Telegram for promotion, and poor cybersecurity practices such as lack of endpoint security and user awareness. 

#### Threat actor/group/campaign 
 The exact threat actors are not disclosed, but the malware are associated with different developers promoting via underground forums, GitHub, and social media platforms. *Divulge Stealer is promoted on HackForums, Cracked, and GitHub* (https://securityonline.info/divulge-dedsec-and-duck-the-rise-of-advanced-stealer-malware/). 

#### Organization/industry/location 
 The malware targets general users, focusing on stealing data from browsers, games, and cryptocurrency wallets. *Divulge Stealer has anti-VM capabilities and targets multiple browsers and cryptocurrency wallets* (https://ministang.com/security.php?article=671632274cd6fde9de79aec3). *DedSec Stealer is a copy of Doenerium and employs similar evasion techniques* (https://ministang.com/security.php?article=671632274cd6fde9de79aec3). *Duck Stealer is identified as AZStealer and shares functionalities with the others, including anti-VM features and extensive cryptocurrency wallet targeting* (https://ministang.com/security.php?article=671632274cd6fde9de79aec3).

 The blog was published on October 17, 2024. No specific start date is provided for the attack campaigns. *New publication date: October 29, 2024* (https://securityonline.info/divulge-dedsec-and-duck-the-rise-of-advanced-stealer-malware/).

#### Incident: Fake attachment. Roundcube mail server attacks exploit CVE-2024-37383 vulnerability 

#### Root cause 
 The root cause is a stored XSS vulnerability (CVE-2024-37383) in the Roundcube Webmail email client. This vulnerability allows attackers to execute JavaScript code on the user's page by exploiting improper handling of SVG elements within the email body markup *due to improper sanitization of SVG animate attributes* (https://security.snyk.io/vuln/SNYK-PHP-ROUNDCUBEROUNDCUBEMAIL-8235206). 

#### Threat actor/group/campaign 
 Unknown threat actors *attempted to exploit the vulnerability* (https://www.betterworldtechnology.com/post/hackers-exploit-roundcube-webmail-xss-vulnerability-to-steal-login-credentials). 

#### Organization/industry/location 
 A governmental organization in a CIS country. 

#### Start date – End date 
 June 2024 - September 2024 

#### MITRE TTPs 
 ['T059.007: Execution via JavaScript', 'T1114.003: Remote email collection using the ManageSieve plugin', 'T1056.004: Web portal capture involving login and password input fields'] 

#### Impact 
 Potential unauthorized access to email accounts, theft of credentials, and corporate email communications. *Victims tricked into revealing credentials via fake login forms embedded in Roundcube’s interface* (https://socradar.io/roundcube-vulnerability-cve-2024-37383-exploited-in-phishing-attacks-targeting-government-agencies-for-credential-theft/). *Captured credentials were sent to a remote server hosted on Cloudflare* (https://www.betterworldtechnology.com/post/hackers-exploit-roundcube-webmail-xss-vulnerability-to-steal-login-credentials). 

#### Mitigation Steps 
 ['**Update Roundcube Webmail**: Ensure that your Roundcube Webmail installation is updated to version 1.5.7 or later, or version 1.6.7 or later, where the vulnerability has been patched.', '**Regular Software Updates**: Maintain a regular schedule for updating all software to the latest versions to avoid vulnerabilities.', '**Email Filtering**: Implement robust email filtering to detect and quarantine suspicious emails.', '**User Training**: Train users to recognize and avoid phishing attempts and suspicious emails.', '**Content Security Policy (CSP)**: Implement a strict Content Security Policy to restrict the execution of scripts in emails.']
