# MAR-10454006-r2.v1 SEASPY Backdoor

**Incident: SEASPY Backdoor on Barracuda Email Security Gateway**

**Root cause:** Exploitation of CVE-2023-2868 vulnerability in Barracuda Email Security Gateway (ESG) versions 5.1.3.001-9.2.0.006.

**Impact:** Undisclosed number of records leaked and potential unauthorized access to affected systems. The specific number of devices, people impacted, and financial losses are not provided in the document.

**Mitigation:** Apply the following detailed steps to mitigate the SEASPY backdoor:
1. **Patch the Vulnerability:**
   - Ensure that all Barracuda ESG appliances are updated to the latest firmware version that addresses CVE-2023-2868.
2. **Identify and Remove Malware:**
   - Use the provided YARA rules to detect SEASPY malware on Barracuda ESG appliances.
   - Quarantine and remove detected malware files.
3. **Harden System Configurations:**
   - Disable unnecessary services and ports on ESG appliances, particularly SMTP (port 25) and TCP port 587 unless strictly necessary.
   - Implement strict access controls to limit who can execute commands on the appliance.
4. **Enhance Monitoring:**
   - Monitor network traffic for unusual patterns, especially traffic directed to C2 servers from ESG appliances.
   - Use intrusion detection systems (IDS) to detect the specific hardcoded string "oXmp" used by SEASPY.
5. **Authentication and Authorization:**
   - Require strong authentication mechanisms for accessing ESG management interfaces.
   - Regularly review and update user permissions to ensure least-privilege access.
6. **Incident Response Plan:**
   - Develop and implement an incident response plan for potential malware infections.
   - Train staff on recognizing and responding to security incidents.
